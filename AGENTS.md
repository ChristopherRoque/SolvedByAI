# SolvedByAI

Public repo. Anything committed here is seen by anyone.

- One folder per build in `builds/`, copied from `builds/_template/`. Each build stands on its own.
- No secrets, no client data, no real customer names, no voice or face files.
- Add each new build to the table in README.md.
- Reel production lives in the private `content` repo, not here.
